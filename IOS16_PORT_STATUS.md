## Verified

The complete FEX library, shadPS4 native core and Swift app compiled and linked using Xcode 16.4. The IPA was downloaded and independently checked on macOS:

- ZIP integrity and artifact digest matched.
- Main executable: arm64, iOS minimum 16.2.
- BreakpointJIT minimum: 15.0; bundled Vulkan library minimum: 13.0. All three binaries target device iOS.
- Ad hoc signature passed strict recursive verification.
- Signed entitlements include get-task-allow, dynamic-codesigning and increased-memory-limit.
- No imports of the nine floating-point std::to_chars functions introduced in iOS 16.3 remain in the main executable. LLVM's implementations are statically linked instead.
- No imports of the iOS 17.4 os_sync_wait_on_address / wake_by_address functions remain in the main executable.
- Swift source typechecking, reader/writer lock contention tests, cancellation-aware wait tests and floating conversion tests passed.

## Compatibility changes

- Backported Observation ownership and SwiftUI APIs to their iOS 16 equivalents.
- Recovered a complete native CMake entry from upstream history, connected the vendored FEX build, and rebuilt dependencies at the 16.2 deployment target.
- Replaced new Darwin wait primitives with condition-variable synchronization.
- Connected the existing jthread polyfill and corrected cancellation-aware wait behavior, including a synchronous callback deadlock found by testing.
- Built a static LLVM 19 floating-point charconv backport. The availability override is limited to these implemented overloads; other SDK availability checks remain enabled. The archive is force-loaded to prevent accidental imports from the newer system libc++.
- On iOS 16, JIT allocation attempts entitlement-backed mmap and fails cleanly if denied. Newer iOS versions retain the upstream external-debugger protocol.
- Removed desktop-only hardware probes, replaced shell-based directory creation, built the native font embedding utility, and linked SDL's required CoreMotion framework.
- The Xcode project is regenerated by the build script; generate_project.rb is the canonical packaging configuration.

## Build and installation

Run the repository's “Build experimental iOS 16.2 IPA” Actions workflow. It fetches pinned dependencies and LLVM source, builds the native libraries, generates the Xcode project, and packages an ad hoc signed IPA with the required entitlements. The additional app audit script is also tested locally and gates subsequent packaging.

Transfer the IPA to the phone and install with TrollStore. The bundled startup check must successfully allocate JIT memory before guest execution can be considered available.
